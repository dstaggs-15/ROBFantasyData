# Rock or Bust Fantasy League Archive

The source data and public history hub for the Rock or Bust fantasy football league.

The site in `docs/` combines verified standings, weekly matchup scores, draft history,
manager profiles, rivalry comparisons, championships, and clearly labeled reconstructed
history. GitHub Pages deploys the contents of `docs/` whenever `main` changes.

## Data coverage

- Recognized league history: 2020-present (early seasons are partial)
- Complete final ranks and draft results: 2022-2024
- Weekly matchup scores: 2025 Weeks 1-11 in the current snapshot
- Current manager identities and divisions: 2025

The interface uses permanent manager identities rather than team names so renamed teams
do not split a person's historical record.
